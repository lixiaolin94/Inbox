## 分段（按序执行）

### A. 输入框单行修复（MainViewController.setUpInput）

按设计 §A：`usesSingleLineMode` / cell `wraps=false` / `isScrollable=true` / `.byClipping`。

### B. 列表多行 + 顶对齐（RecordCellView / MainViewController / GroupHeaderCellView / ResolvedSectionHeaderCellView）

按设计 §B 全文执行。要点复述：
- RecordCellView：content 换 word-wrap 多行；priority/time 改 firstBaseline 对齐 content；content top/bottom 钉住 cell，整体最小高度语义 ≥28pt（与现单行行高一致）。压缩阻力保持低，防止内容顶宽窗口。
- 主表 `usesAutomaticRowHeights = true`，删除 MainViewController 的 `heightOfRow` 委托；两个 header cell 自带高度约束（24 / 22）。
- Trash 表不开 automaticRowHeights、保留其现有行高路径——检查 TrashViewController 是否有自己的 heightOfRow（有则保留）。
- UISmokeRunner 新增断言：创建一条超长内容（如 120 个 ASCII 字符）Record 后，该行行高 > 40pt；需要在 MainViewController 加 smoke hook `func smokeRowHeight(forRecordID:) -> CGFloat?`（用 tableView.rect(ofRow:).height）。断言后把这条 Record ⌫ 掉恢复列表状态，避免影响后续步骤。

### C. 沉浸窗口（AppDelegate）

按设计 §C：titleVisibility hidden、titlebarAppearsTransparent、isMovableByWindowBackground；title 字符串保留。UISmokeRunner 在窗口几何步骤加断言 `window.titleVisibility == .hidden`。

### D. iCloud 开关 + 离线标签（SyncEngine.shouldEnable / AppDelegate / MainViewController）

按设计 §D 全文执行。要点复述：
- defaults 键 `com.inbox.syncEnabled` 缺省视为 true；`shouldEnable` 尊重它。
- App 菜单 "iCloud Sync" checkbox：validateMenuItem 反映状态、无 entitlement 时禁用；toggle 写 defaults + alert "更改将在下次启动 Inbox 时生效"（英文 UI 请用 "Takes effect the next time Inbox launches."，菜单项英文 "iCloud Sync"）。
- 离线标签：utility bar Trash 左侧，文案 "iCloud unavailable · offline"，默认隐藏；AppDelegate 在 engine 非 nil 时 Task 查 accountStatus，非 .available 时主线程调 `mainViewController.showOfflineNotice(true)`。engine 为 nil（开关关/无 entitlement/smoke）不显示。
- ui-smoke 下 engine 本来就禁用——确认冒烟不受影响。

### E. Scope Bar chip 接受 record 拖放（ScopeChipButton / ScopeBarView / MainViewController）

按设计 §E 全文执行。要点复述：
- 新小文件 `Sources/Inbox/RecordDragTypes.swift`：`enum RecordDragTypes { static let recordID = NSPasteboard.PasteboardType("com.xiaolin.inbox.record-id") }`；MainViewController 原 `recordIDPasteboardType` 改引用它（保持行为不变）。
